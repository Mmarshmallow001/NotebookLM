# NotebookLM
Desafio -  Riachuelo 

Contexto:
O objetivo da criação do NotbookLM é explorar a transição das "Soft Skills" tradicionais para o conceito de Power Skills no ambiente de trabalho, além de entender quais são as habilidades mais requisitadas e como desenvolve-lás e/ou aprimorá-lás. Inclusive, com o avanço da Inteligência Artificial, habilidades humanas como pensamento crítico, escuta ativa, curiosidade, entre outros, tornaram-se o pilar central da empregabilidade e o principal diferencial.

Objetivos de estudo:
- Entender o que são Soft Skills (Power Skills);
- Como desenvolver e/ou aprimorá-las;
- Identificar as habilidades mais requisitadas no ambiente de trabalho;
- Ter um guia prático de desenvolvimento dessas competências.

Curadoria de Fontes:
- Para alimentar o NotebookLM, selecionei fontes confiáveis como MIT, Alura, Gupy... para minimizar Alucinações.
